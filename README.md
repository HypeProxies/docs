# HypeProxies customer docs

Source of [docs.hypeproxies.com](https://docs.hypeproxies.com): guides for customers of our hosted services (how to connect, how to use the service, how to fix common problems).

The site is built by GitHub Pages (Jekyll) from the `main` branch. This README and `CONTRIBUTING.md` are not published.

**Adding or changing a guide?** See [CONTRIBUTING.md](CONTRIBUTING.md) and start from [templates/guide-template.md](templates/guide-template.md).
